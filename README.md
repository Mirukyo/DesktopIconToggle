# 桌面图标开关

**DesktopIconToggle** 是一个用于 Windows 的桌面图标隐藏/显示工具。

通过双击桌面、全局快捷键或系统托盘，可以快速切换桌面图标的显示状态。

## 功能

* 双击桌面空白区域隐藏/显示桌面图标
* 全局快捷键隐藏/显示桌面图标
* 自定义快捷键
* 首次启动快捷键设置
* Windows 系统托盘
* 开机自动启动
* 支持 Windows 深色 / 浅色主题
* 自定义应用与托盘图标

## 技术

* Flutter
* Dart
* C++
* CMake
* Windows API

## 构建

进入 Flutter 项目目录：

```powershell
cd ui
```

安装依赖：

```powershell
flutter pub get
```

构建 Windows Release：

```powershell
flutter build windows --release
```
